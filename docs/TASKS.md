# Tasks

Working tracker for Postgres Lab. Newest state at the top of each tier. Update the **Status** and **Verification** cells as work lands — this file is the source of truth for what is done, in progress, or queued.

**Status legend:** `done` (shipped + measured) · `wip` (in progress now) · `next` (queued, agreed) · `todo` (proposed) · `blocked` (needs a decision, noted why)

**Rules:** one task per row; Verification holds the number or command that proves it, not an adjective. Docs (`ARCHITECTURE.md` / `CHANGELOG.md`) get an entry before a row flips to `done`.
